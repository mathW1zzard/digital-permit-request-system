# Project 32 – Digital Permit Request System (Week 13: Automation Foundation)

Flutter Web client + Laravel API. Automates approval routing, expiry reminders, automatic expiration and exception escalation, with bounded retry and human handling of failures. Classroom prototype with fictional data. Not production-ready.

## Requirements

Windows 10/11, PHP 8.3+, Composer 2, Flutter (stable, web enabled), Chrome, Git. All commands below are for Command Prompt (CMD).

## Run it (three CMD windows)

1. Gateway, in the repository root:

       set "GATEWAY_API_KEY=<same value as GATEWAY_API_KEY in backend\.env>"
       php -S 127.0.0.1:9000 mock-gateway\router.php

2. API, in `backend\`:

       composer install
       copy .env.example .env
       php artisan key:generate
       php artisan migrate:fresh --seed
       php artisan serve

   Scheduler (optional, a fourth window in `backend\`): `php artisan schedule:work`

3. Client, in `client\`:

       flutter pub get
       flutter run -d chrome --web-port 5000 --dart-define=API_BASE_URL=http://localhost:8000/api

Sign in with a demo account, e.g. `requester@permit.test` (all accounts: `database\seeders\DatabaseSeeder.php`).

## Tests
